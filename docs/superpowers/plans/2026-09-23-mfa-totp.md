# MFA local (TOTP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make TOTP mandatory for local (email + master password) accounts before the vault opens, per Fase 1 of the auth RFC.

**Architecture:** Login stops issuing tokens directly. `POST /auth/login` now returns a short-lived `mfa_pending` JWT plus a status telling the client whether to run TOTP setup or TOTP verify. Only `/auth/totp/confirm` or `/auth/mfa/verify` issue real `access`/`refresh` tokens. The TOTP secret is a server-known shared secret (RFC 6238), encrypted at rest with a key derived from `JWT_SECRET` — never the user's KEK.

**Tech Stack:** FastAPI + SQLAlchemy (async) + Alembic (backend, existing); `pyotp` (new, TOTP); `cryptography` HKDF+Fernet (already a dependency, new usage). React + Vite (frontend, existing); `qrcode` (new, client-side QR rendering).

**Spec:** `docs/superpowers/specs/2026-09-23-mfa-totp-design.md`

## Global Constraints

- TOTP secret encrypted at rest with Fernet, key = HKDF-SHA256(`JWT_SECRET`, info=`b"totp"`, length=32) — never the user's KEK (spec §3).
- `mfa_pending` JWT: `type="mfa_pending"`, 5 minute expiry, same `JWT_SECRET`/algorithm as existing tokens (spec §4).
- TOTP verification: `pyotp.TOTP(secret).verify(code, valid_window=1)` (spec §4, §9).
- TOTP lockout: same `LOCKOUT_THRESHOLD` and `lockout_duration_minutes()` as password lockout, but a fully independent counter (`totp_failed_attempts`/`totp_locked_until`) — one lockout never affects the other (spec §2, §8).
- Rate limit `5/minute` on `/auth/totp/confirm` and `/auth/mfa/verify`, matching the existing `/auth/login` limiter (spec §8).
- `/auth/totp/setup` returns `409` if `mfa_configured` is already `true` (spec §4, §8).
- No new columns beyond spec §2: `auth_method`, `totp_secret_enc`, `mfa_configured`, `totp_failed_attempts`, `totp_locked_until` on `users`.

## Review Focus

- Malformed `totp_code` (not 6 digits, non-numeric) must be rejected by schema validation (422) before reaching `pyotp` — a crafted string must not crash the endpoint or short-circuit verification.
- Wrong code on `/auth/totp/confirm` must leave `mfa_configured=false` and issue no tokens — a guesser must not be able to partially activate MFA.
- Calling `/auth/totp/setup` twice before confirming must invalidate the first secret: only the most recently generated one verifies successfully — a stale QR code must not silently keep working.
- `/auth/mfa/verify` must reject with a clear error (not a 500) when `mfa_configured` is still `false` — skipping setup must not crash the verify path.
- An `mfa_pending` token is scoped to the `sub` it was issued for — one user's token must not let them drive another user's TOTP setup/confirm/verify.

```python
# backend/app/core/totp.py
import base64

from cryptography.fernet import Fernet
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.kdf.hkdf import HKDF

from ..config import settings


def _totp_fernet_key() -> bytes:
    kdf = HKDF(algorithm=hashes.SHA256(), length=32, salt=None, info=b"totp")
    raw = kdf.derive(settings.JWT_SECRET.encode())
    return base64.urlsafe_b64encode(raw)


def encrypt_totp_secret(secret: str) -> bytes:
    return Fernet(_totp_fernet_key()).encrypt(secret.encode())


def decrypt_totp_secret(token: bytes) -> str:
    return Fernet(_totp_fernet_key()).decrypt(token).decode()
```

```python
async def get_mfa_pending_user(
    creds: HTTPAuthorizationCredentials = Depends(security),
    db: AsyncSession = Depends(get_db),
) -> User:
    token = creds.credentials
    try:
        user_id = verify_token(token, "mfa_pending")
    except ValueError:
        raise HTTPException(status_code=401, detail="invalid or expired mfa token")
    user = await db.get(User, user_id)
    if not user:
        raise HTTPException(status_code=401, detail="user not found")
    return user
```

```python
    session = Session(

@router.post("/totp/setup", response_model=TotpSetupOut)
async def totp_setup(
    user: User = Depends(get_mfa_pending_user), db: AsyncSession = Depends(get_db)
):
    if user.mfa_configured:
        raise HTTPException(409, "TOTP already configured")
    secret = pyotp.random_base32()
    user.totp_secret_enc = encrypt_totp_secret(secret)
    await db.commit()
    uri = pyotp.totp.TOTP(secret).provisioning_uri(name=user.email, issuer_name="VaultLocal")
    return TotpSetupOut(secret=secret, otpauth_uri=uri)


@router.post("/totp/confirm", response_model=TokenOut)
@limiter.limit("5/minute")
async def totp_confirm(
    request: Request,
    body: TotpCodeIn,
    user: User = Depends(get_mfa_pending_user),
    db: AsyncSession = Depends(get_db),
):
    if not user.totp_secret_enc:
        raise HTTPException(400, "call /auth/totp/setup first")
    secret = decrypt_totp_secret(user.totp_secret_enc)
    if not pyotp.TOTP(secret).verify(body.totp_code, valid_window=1):
        raise HTTPException(401, "invalid totp code")
    user.mfa_configured = True
    await db.commit()
    return await _issue_session_tokens(db, user.id)


@router.post("/mfa/verify", response_model=TokenOut)
@limiter.limit("5/minute")
async def mfa_verify(
    request: Request,
    body: TotpCodeIn,
    user: User = Depends(get_mfa_pending_user),
    db: AsyncSession = Depends(get_db),
):
    if not user.mfa_configured or not user.totp_secret_enc:
        raise HTTPException(400, "totp not configured")
    secret = decrypt_totp_secret(user.totp_secret_enc)
    if not pyotp.TOTP(secret).verify(body.totp_code, valid_window=1):
        raise HTTPException(401, "invalid totp code")

    user.totp_locked_until = None
```

```python
@router.post("/mfa/verify", response_model=TokenOut)
@limiter.limit("5/minute")
async def mfa_verify(
    request: Request,
    body: TotpCodeIn,
    user: User = Depends(get_mfa_pending_user),
    db: AsyncSession = Depends(get_db),
):
    now = datetime.now(timezone.utc)
    locked_until = _aware(user.totp_locked_until)
    if locked_until and locked_until > now:
        retry_after = int((locked_until - now).total_seconds())
        raise HTTPException(429, f"totp locked, try again in {retry_after}s")

    if not user.mfa_configured or not user.totp_secret_enc:
        raise HTTPException(400, "totp not configured")

    secret = decrypt_totp_secret(user.totp_secret_enc)
    if not pyotp.TOTP(secret).verify(body.totp_code, valid_window=1):
        user.totp_failed_attempts += 1
        if user.totp_failed_attempts >= LOCKOUT_THRESHOLD:
            minutes = lockout_duration_minutes(user.totp_failed_attempts)
            user.totp_locked_until = now + timedelta(minutes=minutes)
        await db.commit()
        raise HTTPException(401, "invalid totp code")

    user.totp_failed_attempts = 0
    user.totp_locked_until = None
    return await _issue_session_tokens(db, user.id)
```
